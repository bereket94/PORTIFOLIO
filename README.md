# Bereket Asfaw Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
Open this folder in VS Code and use the Live Server extension, or run a local static server.

## Files
- `index.html` - page content
- `style.css` - responsive design and styling
- `script.js` - mobile navigation, reveal effects, section navigation and EmailJS form
- `photo/` - existing portfolio images

## Before publishing
1. Check that `photo/pgh.jpg` is the portrait you want to publish.
2. Confirm your EmailJS service and template are still active.
3. Add your real LinkedIn / other social profile URLs if you want them displayed.
4. Add a current CV PDF if you want a downloadable CV button.
